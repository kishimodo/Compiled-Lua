# E001: syntax error near symbol

## What it means

The Lua front-end could not parse the source at the reported location.
The `near '<token>'` clause names the token where the parser gave up --
usually the token is fine and the real mistake is one token earlier.

## Common causes

- Using `=` instead of `==` inside a condition
- A missing `then`, `do`, or `end` keyword
- A stray comma, semicolon, or closing bracket
- Using a Lua 5.1 idiom Lua 5.4 no longer accepts
  (for example `arg[0]` in the main chunk)

## Fix

```lua
-- Wrong: assignment where a comparison belongs
if x = 1 then
  print("hi")
end

-- Right:
if x == 1 then
  print("hi")
end
```

```lua
-- Wrong: missing `then`
if x == 1
  print("hi")
end

-- Right:
if x == 1 then
  print("hi")
end
```
