# E009: cannot resolve `require`

## What it means

`require "<name>"` names a module the compiler could not find on any
of its search paths: the base directory (relative to the entry file),
the extra `--include` directories, the rover package store, and the
built-in package tree. Because CLua compiles a closed world every
required module must resolve at build time -- there is no lazy
`package.loaders` fallback.

## Common causes

- A typo in the module name
- The dependency is not installed (`rover add <name>` never ran)
- The dependency is in a directory the compiler does not search
- `require(variable)` where the argument is not a string literal (a
  dynamic require cannot be resolved statically; see the compiler's
  "dynamic require" warning and use `-L <pkg>` to force-bundle)

## Fix

```lua
-- Wrong: typo -- there is no module 'jsn'
local jsn = require "jsn"

-- Right:
local json = require "json"
```

```sh
# Missing dependency: install it
rover add json
```

```sh
# Add a source directory to the compiler's search path
clua build main.lua --include ./vendor
```
