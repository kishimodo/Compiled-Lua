# E006: `<eof>` expected / unexpected symbol near `<eof>`

## What it means

The parser reached end-of-file while it was still inside a block that
needed a closing keyword (`end`, `until`, `}`, `)`). The error line
usually points at the opening of the unfinished block, not at the last
line of the file.

## Common causes

- A missing `end` on a `function`, `if`, `for`, or `while`
- A missing closing `}` on a table constructor
- A missing closing `)` on a function call that spanned multiple lines

## Fix

```lua
-- Wrong: `if` never closed
local function f(x)
  if x then
    print(x)
end
-- lexer hits EOF still waiting for the `if`'s end

-- Right:
local function f(x)
  if x then
    print(x)
  end
end
```

## Tip

An editor that indents blocks helps: an unclosed `if` shows one extra
level of indentation on every line after it. When the whole file drifts
right, look for the unclosed block near the top of the drift.
