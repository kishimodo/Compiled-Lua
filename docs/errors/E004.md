# E004: unfinished long comment

## What it means

A long comment (`--[[ ... ]]`) or long bracket (`--[==[ ... ]==]`) was
opened but never closed. The lexer read all the way to end-of-file
still looking for the matching close bracket at the same level.

## Common causes

- A typo in the closing bracket (`]]` written as `] ]`)
- Forgetting to match the level count between the open and close
  (opened `--[==[` but closed `]]`)
- A stray `--[[` inserted while temporarily commenting out a block

## Fix

```lua
-- Wrong: no matching ]]
--[[ this is a note
     that runs past EOF

-- Right: close the comment
--[[ this is a note
     that runs past EOF ]]
```

```lua
-- Wrong: level mismatch
--[==[ note with ]] inside
       body ]]              -- lexer expected ]==]

-- Right: match the level
--[==[ note with ]] inside
       body ]==]
```
