# E008: undefined global

## What it means

The code reads a global name that is neither a Lua standard-library
symbol nor defined anywhere in the compiled tree. Under CLua's
closed-world compile the global does not exist at run time -- the read
returns `nil`, and any dereference downstream throws E002 or E007.

## Common causes

- Typos in a function or module name
- Using a global that was defined only in an interactive interpreter
  session (`x = 1` at the REPL is not in the AOT tree)
- Forgetting `local` in a function that uses a variable declared in
  a sibling function

## Fix

```lua
-- Wrong: `helper` is not defined in this tree
local function greet(who)
  return helper(who)     -- warns: undefined global 'helper'
end

-- Right: declare or require it
local function helper(x) return "hi " .. x end
local function greet(who)
  return helper(who)
end
```

```lua
-- If the name IS defined in another module, require it
local util = require "util"
util.helper(x)
```

## Notes

Under `--Werror` an undefined global fails the build. Without
`--Werror` it becomes a warning and the build continues -- the
run-time error surfaces later.
