# E005: `<name>` expected

## What it means

The parser was looking for an identifier at the reported position -- a
variable name, a function name, or a field name -- and found something
else (a keyword, an operator, a literal, or `end`-of-file).

## Common causes

- Using a Lua reserved word as a variable name
  (`local end = 1`, `local function then() end`)
- Missing name after `local`, `function`, or `for`
- Extra comma at the end of a declaration list

## Fix

```lua
-- Wrong: reserved word as variable
local function then()
  print("hi")
end

-- Right: pick another name
local function later()
  print("hi")
end
```

```lua
-- Wrong: trailing comma leaves no name after it
local a, b, = 1, 2

-- Right:
local a, b = 1, 2
```
