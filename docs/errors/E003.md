# E003: unfinished string literal

## What it means

The lexer walked past the end of the line (or the end of the file)
while it was still inside a single- or double-quoted string, so it
never saw the closing quote.

Lua's short strings do not span lines. A newline inside `"..."` or
`'...'` ends the string implicitly and the parser reports E003 at the
line where the string started.

## Common causes

- A quote character used inside a string without escaping (`"he said "hi""`)
- Continuing a string across multiple lines without switching to the
  `[[...]]` long-string form
- A trailing backslash that looks like a line continuation but is not

## Fix

```lua
-- Wrong: embedded quote closes the string too early
local s = "he said "hi" to me"

-- Right: escape the inner quotes
local s = "he said \"hi\" to me"
-- or switch to single quotes
local s = 'he said "hi" to me'
```

```lua
-- Wrong: multi-line short string
local msg = "hello
world"

-- Right: use a long string
local msg = [[hello
world]]
```
