# W001: unused local

## What it means

A local variable was declared and written but never read. The compile
succeeds -- W001 is advisory. Under `--Werror` any warning fails the
build.

The scanner uses Lua's own `LocVar` debug information to bound each
name's live range, so nested loops that re-use the same slot for
different names never false-positive on each other.

## Common causes

- A leftover local from an earlier iteration on the code
- Debugging print calls whose local was inlined during cleanup
- A `for` loop variable that was renamed but the old one still
  declared

## Fix

If the local is truly unused, remove it. If it's kept intentionally
(a placeholder for a future field, an interop pattern) rename it to
start with an underscore so this pass ignores it.

```lua
-- Wrong: unused local
local function f()
  local u = 1
  return "hi"
end

-- Right: drop it
local function f()
  return "hi"
end

-- Or if the placeholder is intentional
local function f()
  local _u = 1
  return "hi"
end
```

## Suppression

Silence W001 for one build with `-w`, or globally with `-Wno-unused`.
Turn every warning into a failure with `--Werror`.
