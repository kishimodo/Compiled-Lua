# E002: attempt to call a nil value

## What it means

The program indexed a table or upvalue that evaluated to `nil` and then
tried to call it as if it were a function. Under CLua's closed-world
compile the offending name is not injected at run time -- the compiler
either sees the definition or the reference resolves to `nil`.

## Common causes

- A typo in the function name (`prnit(x)` instead of `print(x)`)
- Forgetting to `require` the module that defines the function
- Calling a method with `.` instead of `:` and forgetting `self`
- Reading a table field before it was assigned

## Fix

```lua
-- Wrong: typo in the name
local function greet(who)
  prnit("hi " .. who)   -- prnit is nil
end

-- Right:
local function greet(who)
  print("hi " .. who)
end
```

```lua
-- Wrong: forgot to require the module
local ok = json.encode({x = 1})  -- `json` is nil

-- Right:
local json = require "json"
local ok   = json.encode({x = 1})
```
