# release notes

release notes are maintained in the top-level `CHANGELOG.md` file at the
repo root. this page will render the changelog once the site build has a
plugin configured to include external markdown; for now it exists so the
navigation in the site does not point at a missing file.

the changelog is the source of truth for what changed in each release
and which limitations are known at the time of that release. the file
lives at:

```
CHANGELOG.md
```

in the repository root.
