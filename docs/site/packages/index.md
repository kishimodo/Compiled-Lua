# packages

the built-in packages ship as part of the runtime archive. a program
that does not reference a package does not carry it in the compiled
exe.

the per-package pages are generated by `tools/gen-package-docs.lua`,
which scans `clua/src/runtime/packages/*/init.lua` for a documentation
header (a top comment block with a specific fence) and writes one
`<name>.md` file per package into this directory.

until the packages themselves are updated to carry the documentation
fence, each generated page is a stub with a note pointing at the
package source. the generator emits one page per package regardless,
so links from other pages do not go stale.

the full list of package pages will appear here once the generator has
been run against a tree that has documentation headers in place. the
current arc ships the scanner; the package updates are a follow-up.
